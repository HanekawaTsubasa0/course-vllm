## 检查口径

### 文件与结构

正式文件按固定清单检查，不使用目录通配结果代替课程清单，因此旧草稿不会被误算为正式讲义。每篇文件至少检查标题、章节层级、实验或证据任务、自检问题和参考资料。

### Markdown 完整性

统计所有以三个反引号开头的围栏，并验证数量为偶数。Mermaid 围栏单独计数，用于确认图示没有在编辑过程中丢失。

### 内容遗留项

全量扫描常见占位符和错误域名。普通语义中的“尚未完成”不视为占位符，例如 Week 11 对 waiting request 的定义。

### 链接

共识别 73 处 HTTP/HTTPS 链接，去重后 30 个。检查了链接文本和域名拼写；外部站点可访问性会随网络、登录状态和站点策略变化，因此不把一次网络响应作为内容正确性的唯一证据。

## 后续修改要求

后续若调整某一周，至少重新检查四件事：代码围栏是否闭合、图示是否仍可渲染、实验口径是否随正文更新、参考链接是否仍然对应文中论点。若篇幅或图示数量发生变化，也应同步更新总目录中的交付统计。
