# 全书重构计划

## 总体原则

旧版讲义保留在 Git 历史和当前各章文件中作为知识点素材。新版本不以“尽量少改旧稿”为目标，而以知识依赖、课堂叙事和后续 PPT 复用为目标。

## 状态标记

- `样章完成`：已经按新规范重写，可用于确认风格。
- `待重写`：正文仍主要来自上一版，只作为素材。
- `暂缓`：保留概念内容，但当前不开发实验。

## 分批顺序

1. 评审第 3、10 章来源驱动样章，确定正式程度、引用密度、图表形式和课堂时长。
2. 重写第 1、2、8、9、11 章，形成完整的 Serving 主线。
3. 重写第 4 至 7 章，补齐算子主线并统一数学符号。
4. 重写第 12、13、15、16 章，完成系统优化、规模化和综合论证。
5. 在硬件与 CANN 环境确定前，第 14 章只维护概念导读。

每完成一章，同时整理 `assets/weekXX/`，确保讲义定稿后可以按“小节 -> 幻灯片组”生成 PPT，而不是另写一套内容。
